## 0. 全局骨架

```text
┌─ Shell ─────────────────────────────────────────────────────┐
│ MDCS                                    v1.x · 主题 · 帮助 │
├─ Nav (240) ─┬─ Main ────────────────────────────────────────┤
│ 主界面       │ ┌─ PageHeader ─────────────────────────────┐ │
│ 手动任务     │ │ H1 标题              [次要] [主按钮]      │ │
│ 刮削记录     │ └──────────────────────────────────────────┘ │
│ 演员管理     │ ┌─ Toolbar ────────────────────────────────┐ │
│ 文件管理     │ │ 搜索 · 筛选 · 批量操作                    │ │
│ ─ 系统 ─     │ └──────────────────────────────────────────┘ │
│  数据源      │ ┌─ Content ────────────────────────────────┐ │
│  设置        │ │ 列表 / 表单 / 双栏 / 卡片网格             │ │
│              │ │                                          │ │
│ 宽屏 · 主题  │ └──────────────────────────────────────────┘ │
│              │                    [浮动：保存修改]（设置页） │
└──────────────┴──────────────────────────────────────────────┘
```

**规则**

- Nav 宽度固定；宽屏模式仅加宽 Main，不改 Nav 顺序。
- PageHeader / Toolbar / Content 垂直间距统一（16–20）。
- 设置页保存按钮：**右下角固定**，不跟滚动消失。

## 9. 响应式断点（实现约定）

| 宽度 | 行为 |
|------|------|
| ≥1280 | 完整骨架；Dashboard 四卡一行；详情双栏 |
| 960–1279 | Nav 可折叠为图标；Dashboard 2×2 |
| <960 | Nav 抽屉；详情上下堆叠；水印预览改下方 |

## 10. 实现对照清单

前端每个路由落地时勾选：

- [ ] 符合 §0 全局骨架（Header / Toolbar / Content）
- [ ] 文案取自 `UI-COPY.md`，无硬编码散落
- [ ] 主操作在右上或弹窗右下，危险操作有确认
- [ ] 列表具备搜索/筛选/分页（适用页）
- [ ] 空状态含「状态 + 建议 + 按钮」
- [ ] 设置页保存条不随滚动丢失
- [ ] 窄屏不断档（见 §9）
