## 0. 北极星：什么叫「相对完美」

相对 8 个参考项目，MDCS 要同时做到：

| 维度 | 超越谁 | MDCS 标准 |
|------|--------|------------|
| **信息架构与配置粒度** | MDC-NG | 11 Tab + 七路径 + 任务级覆盖，字段可验收 |
| **七路径语义** | 色花 | 含日本写真；每区独立 source/library |
| **番号识别** | JavSP | 规则集对齐 `avid.py` 上限 |
| **多源聚合** | 色花 + Javinizer | FAST/SLOW + 字段优先级「非空不回退」+ fieldSources |
| **整理安全** | Javinizer | dry-run / 目录白名单 / 可选 revert；默认硬链接 |
| **体验** | 全体桌面/Web 壳 | PLAYBOOK + COPY + WIREFRAMES 验收 |
| **规模** | 多数玩具项目 | 20 万文件：增量、断点、失败隔离 |
| **独立可控** | 色花/mdcx | **零运行时依赖**参考源码，自有前后端 |

**明确不做**：磁力库、Jellyfin 插件壳、软链/原地整理、默认清理源目录。

## 2. 执行规则（每一步都遵守）

1. **一步一事**：下方每个 **Sx.y** 是一个可合并/可验收的小步骤（建议 0.5～2 人日）。
2. **先验收后开下一步**：每步有「完成标准」，不过不进入下一步。
3. **文档优先于臆测**：字段/文案/布局分别查 DESIGN / COPY / WIREFRAMES。
4. **参考只读**：改 MDCS 代码，不改 `references/`，不接色花运行时。
5. **风险默认关**：移动整理、清理源目录、Webhook 批量 — 默认关或需确认。
6. **可回退**：大改前保留可运行的 `main`/`dev`；破坏性迁移单独一步。
