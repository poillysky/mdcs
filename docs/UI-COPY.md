# MDCS — UI 标准文案库

> 版本：v1.0  
> 日期：2026-08-20  
> 用途：按钮、标签、提示、空状态、错误文案的**唯一中文标准**  
> 关联：[`UI-PLAYBOOK.md`](UI-PLAYBOOK.md)（体验规则）· [`DESIGN.md`](DESIGN.md)（功能规格）  
> 代码落点：优先写入 `apps/web/src/lib/messages.ts` / 页面常量，禁止页面内硬编码散落文案

---

## 1. 文案原则

| 原则 | 说明 |
|------|------|
| 动作 + 结果 | 「保存修改」「创建任务」，不用「OK」「确定」泛化 |
| 一句说清 | 主文案 ≤ 20 字；说明 ≤ 2 行 |
| 失败可恢复 | 错误 = **原因 + 建议动作** |
| 术语统一 | 全站同一概念只用一个词（见 §2） |
| 风险明示 | 覆盖/删除/移动前必须说清后果 |

| 数据源（全关） | 尚未启用任何数据源 | 至少开启一个 Provider 才能刮削 | 前往配置 |
| 最近活动 | 暂无最近活动 | 刮削成功后会显示在这里 | — |

## 10. 设置 Tab

### 10.1 Tab 标题

`整理` · `监控` · `下载` · `命名` · `水印` · `网络` · `元数据` · `NFO` · `演员` · `系统` · `Webhook`

### 10.2 页脚动作

| Tab | 动作 |
|-----|------|
| 通用 | 保存修改 |
| 命名 | 导出 · 导入 · 命名测试 · 保存修改 |
| Webhook | 保存更改 |
| 系统 / 网络 | 测试连接 · 保存修改 |

### 10.3 整理 Tab 关键文案

| 字段 | 标签 | 说明 |
|------|------|------|
| sourceRoot | 来源目录 | 该路径分类的输入目录 |
| libraryRoot | 输出目录 | 整理结果存放目录 |
| enabled | 启用此分类 | — |
| hardlink | 硬链接 | 同盘不占额外空间；跨盘请配置降级为复制 |
| copy | 复制 | 保留来源文件 |
| move | 移动 | 会删除来源文件，请谨慎使用 |
| 自动清理 | 自动清理源目录 | 有风险，默认关闭 |

### 10.4 监控 / 下载 / 命名 / 水印（摘要）

| 字段 | 文案要点 |
|------|----------|
| 性能模式 | 实时监听，要求本机原生目录 |
| 兼容模式 | 约 30 秒轮询，适合 SMB/NFS |
| 缩略图策略·优先级 | 按数据源优先级下载 |
| 缩略图策略·质量 | 比较文件大小选最大（较慢） |
| 命名测试 | 输入样例后预览目录名与文件名 |
| 启用水印 | 为下载的图片叠加角标 |
| 显示全部水印 | 预览时叠加所有已启用类型 |

### 10.5 网络 / 元数据 / NFO / 系统 / Webhook

| 字段 | 文案 |
|------|------|
| 代理地址 | 支持 http 与 socks5 |
| FlareSolverr | 受 Cloudflare 保护的站点自动过盾 |
| 严格字段模式 | 关键字段缺失时视为刮削不完整 |
| 强制校验图片 | 封面或缩略图失败则整条失败 |
| 启用 NFO | 根据刮削数据生成 .nfo 文件 |
| 演员 Tab 占位 | 即将推出 |
| 刮削任务线程数 | 同时并行的工作线程数 |
| 启用 Webhook | 任务完成或失败时发送 HTTP 通知 |
| 触发事件 | 刮削成功 · 刮削失败 |
| 添加 Endpoint | 添加 Endpoint |
| Body 说明 | 使用 Jinja2；变量不存在时渲染为空 |

## 12. 错误文案库（API → 用户）

| 原始/语义 | 用户文案 |
|-----------|----------|
| Failed to fetch / NetworkError | 无法连接后端服务，请确认服务已启动 |
| ECONNREFUSED | 后端拒绝连接，请确认 9210 端口已启动 |
| timeout | 请求超时，请检查网络或代理 |
| Not Found | 接口不存在 |
| 任务不存在 | 任务不存在 |
| 缺少 code | 请填写番号 |
| 刮削已禁用 | 在线刮削已关闭，请先在数据源页开启 |
| 无缓存 | 没有找到该番号的缓存 |
| 源暂未实现 | 该数据源尚未实现 |
| 所有源均未返回有效元数据 | 所有数据源都没有返回有效信息 |
| 无效 kind | 分区无效：{id} |
| 分区不可用 | 分区不可用：{id} |
| HTTP 4xx/5xx | 远程站点返回 {code}，无法访问 |
| 路径不在白名单 | 路径不在允许范围内，请选择已配置的来源或输出目录 |
| 未绑定来源 | 请先绑定来源目录后再扫描 |

## 13. 落地约定

1. 新增页面文案先查本表，无则追加本节再写代码。
2. 英文接口错误必须经 `localizeMessage`（或等价层）转中文后再 Toast。
3. 按钮文案与 §3.1 冲突时，以本表为准改 UI，不改用户习惯迁就旧代码。
4. Phase 4 演员相关文案可先占位，勿编造未实现功能的成功提示。
