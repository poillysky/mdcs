# MDCS — 全站 UI 设计规范（强制契约）

> 版本：v1.0  
> 日期：2026-08-21  
> 性质：**项目设计契约**（非提示词）。Cursor / 人工改 `apps/web` 视觉时必须遵守。  
> Cursor 规则入口：[`.cursor/rules/ui-design-system.mdc`](../.cursor/rules/ui-design-system.mdc)  
> 关联：[`UI-PLAYBOOK.md`](UI-PLAYBOOK.md)（体验流程）· [`UI-COPY.md`](UI-COPY.md)（文案）· [`UI-WIREFRAMES.md`](UI-WIREFRAMES.md)（结构）· [`UI-DENSITY.md`](UI-DENSITY.md)（紧凑与协调排版）· [`UI-IOS.md`](UI-IOS.md)（iOS 显示与触控）

**冲突裁决**：视觉风格以本文为准；功能 IA / 文案以 DESIGN·COPY·WIREFRAMES 为准。旧暗色发光主题视为待迁移遗留，不得继续扩张。

---

## 0. 核心总则

1. **定位**：极简、克制、干净、高级审美；轻质感现代网页。无网红模板风、无廉价科技感。
2. **原则**：留白优先、层级清晰、统一克制、零多余装饰。
3. **约束**：所有页面、组件、动画、配色必须遵循本文；禁止自主新增风格、配色、特效。
4. **优先级**：整洁留白 > 信息层级 > 轻微质感 > 交互动效。

---

## 1. 全局视觉风格

### 1.1 气质

- 现代极简、轻量、通透干净
- 低冲突、耐看、克制不张扬
- 版式透气、专业质感

### 1.2 禁止清单（红线）

| 禁止 | 说明 |
|------|------|
| 渐变与发光 | 流体/多彩/径向大渐变、霓虹、科技蓝光背景、`--accent-glow` 类光晕 |
| 杂乱装饰 | Blob、漂浮几何、乱点缀 |
| 高饱和 | 撞色、彩虹、彩色文字乱跳 |
| 厚重材质 | 大黑阴影、粗边框、立体厚卡片 |
| 夸张动效 | 弹跳、翻转、粒子、花哨滚动 |
| 拥挤 | 留白不足、模块堆砌、信息过密 |
| 廉价感 | 卡通、emoji 滥用、网红 UI 模板 |

## 2. 布局与栅格

### 2.1 栅格

- 标准 **12 列**栅格
- 主内容最大宽度：**1280px**（上限 1320px）
- 区块/卡片严格对齐，禁止随意错位

### 2.2 留白

- 区块间距用间距刻度（见 §5）；**配置/列表场景按 [`UI-DENSITY.md`](UI-DENSITY.md) 偏紧选用**，首屏与空状态仍保持透气
- 页面首区（标题+工具栏）保持可读，不塞满装饰
- 内容区左右安全边距：桌面 **≥ 24px**，移动 **≥ 16px**
- 禁止借「留白」堆出大片无信息空洞；也禁止挤到难扫、难点

### 2.3 对齐

- 正文、列表、表单：**左对齐**
- 仅允许页面级大标题在空状态等场景短文居中；次级标题与正文禁止滥用居中

### 2.4 响应式断点

| 名称 | 宽度 | 行为 |
|------|------|------|
| mobile | `< 768px` | 单列重排；侧栏收起为抽屉/顶栏 |
| tablet | `768–1023px` | 侧栏可缩为 rail；内容单列或双列 |
| desktop | `≥ 1024px` | 侧栏 + 主区；主区 max-width 1280 |

移动端是结构重排，不是整体缩放。

### 2.5 壳层组件约定（S1.4）

MDCS **不以**独立 React `Button`/`Input` 组件库为标准；视觉与交互统一靠：

| 层 | 约定 |
|----|------|
| CSS 类 | `.btn` / `.btn.primary` / `.org-input` / `.org-select` / `.switch` / `.chip` / `.modal*` |
| 布局组件 | `components/ui/PageHeader`、`EmptyState`；业务弹窗 `Modal` |
| Token | `:root` CSS 变量（本文 §3）；禁止页面硬编码主色 |

新增控件优先复用上表类名；确需封装时放 `components/`，样式仍走 Token。

### 2.6 宽屏模式（S1.6）

- 侧栏底「宽屏模式」开关；偏好键 `mdcs.wideMode`
- 开启后 `.app-shell.is-wide .main { max-width: none }`
- **不做暗色主题**（与本文浅色契约一致）

### 2.7 MDCS 壳层（本产品）

- 保留左侧导航 + 右侧主区 IA（见 WIREFRAMES）
- 侧栏宽：**220px**；rail：**64px**
- 主区：`PageHeader` → 工具栏 → 内容；内容容器居中且 `max-width: 1280px`（宽屏模式取消上限）

## 3. 色彩 Token（固定，禁止私改）

### 3.1 逻辑

**1 主色 + 1 辅助色 + 中性灰阶**。彩色总数 ≤ 2（不含功能色）。中性色承担约 **90%** 画面。

### 3.2 调性

低饱和、柔和灰度、浅通透底。无刺眼亮色、无死黑大面积铺底。

### 3.3 色值表（CSS 变量名一并固定）

```css
:root {
  /* 中性 · 背景与表面 */
  --bg: #fafafa;
  --bg-subtle: #f4f4f5;
  --surface: #ffffff;
  --surface-hover: #f4f4f5;

  /* 中性 · 文字 */
  --text: #18181b;
  --text-secondary: #3f3f46;
  --text-muted: #71717a;
  --text-dim: #a1a1aa;

  /* 中性 · 线 */
  --border: #e4e4e7;
  --border-strong: #d4d4d8;

  /* 主色 · 钢青（按钮/选中/导航高亮） */
  --accent: #3d5c63;
  --accent-hover: #334e54;
  --accent-soft: rgba(61, 92, 99, 0.10);
  --accent-text: #ffffff;

  /* 辅助色 · 鼠尾草（仅标签/极小点缀） */
  --secondary: #7d8b74;
  --secondary-soft: rgba(125, 139, 116, 0.14);

  /* 功能色 · 仅状态，不算「品牌彩」 */
  --success: #3f7a5a;
  --success-soft: rgba(63, 122, 90, 0.12);
  --warn: #9a7340;
  --warn-soft: rgba(154, 115, 64, 0.12);
  --error: #a15c5c;
  --error-soft: rgba(161, 92, 92, 0.12);
}
```

### 3.4 用途

| Token | 用途 |
|-------|------|
| `--accent*` | 主按钮、选中态、导航高亮、关键强调字 |
| `--secondary*` | Tag、次要徽章；禁止做大面积底 |
| `--bg` / `--surface` | 页面底 / 卡片与面板 |
| `--text*` | 正文与弱化层级 |
| `--border*` | 细分割线、输入框边 |
| 功能色 | 成功/警告/失败状态，勿当装饰 |

**背景**：纯色浅底或极淡 `--bg-subtle`。禁止花纹、渐变、纹理底。

## 4. 字体与排版 Token

### 4.1 字体（单一无衬线栈）

```css
:root {
  --font: "PingFang SC", "Noto Sans SC", "Segoe UI", "Helvetica Neue", sans-serif;
  --font-mono: "Cascadia Code", "Sarasa Mono SC", "Consolas", monospace;
}
```

禁止混用第二套展示字体；禁止花体、随意斜体、夸张变形。番号/路径可用 `--font-mono`。

### 4.2 字号与字重

| 层级 | Token | 字号 / 行高 | 字重 |
|------|-------|-------------|------|
| 页面大标题 | `--text-page` | 28px / 36px | 600 |
| 区块标题 | `--text-section` | 18px / 28px | 600 |
| 卡片/表头 | `--text-card` | 15px / 24px | 600 |
| 正文 | `--text-body` | 14px / 22px | 400 |
| 辅助/说明 | `--text-help` | 12px / 18px | 400 |
| 标签极小 | `--text-label` | 11px / 16px | 500 |

字重只用 **400 / 500 / 600**，禁止 800–900 粗黑刷屏。

### 4.3 排版

- 正文行高按上表，段落间距 ≥ 12px
- 左对齐为主；字距保持默认，大标题可 `letter-spacing: 0.01em`

## 5. 间距 · 圆角 · 阴影 Token

### 5.1 间距刻度（唯一）

```text
4 · 8 · 12 · 16 · 24 · 32 · 48 · 64
```

| 场景 | 取值 |
|------|------|
| 控件内边距（紧） | 8 / 12 |
| 控件内边距（舒适） | 12 / 16 |
| 表单项间距 | 16 |
| 卡片内边距 | 20–24（用 24） |
| 区块之间 | 32–48 |
| 页面顶底边距 | 24–32 |

### 5.2 圆角（全站统一）

```css
:root {
  --radius-sm: 6px;   /* 按钮、输入、Tag */
  --radius: 10px;     /* 卡片、面板、弹窗 */
  --radius-pill: 999px; /* 仅状态点/极少徽章；默认不用大胶囊堆 */
}
```

禁止同一层级混用直角与大圆角。

### 5.3 阴影（极轻）

```css
:root {
  --shadow-sm: 0 1px 2px rgba(24, 24, 27, 0.04);
  --shadow: 0 4px 16px rgba(24, 24, 27, 0.06);
}
```

禁止多层厚重投影；hover 最多从 `--shadow-sm` → `--shadow`。

## 6. 组件规范

### 6.1 卡片 / 面板

- 底：`--surface`；边：`1px solid --border` 或仅 `--shadow-sm`
- 无装饰线、无图标墙
- hover（可点击卡）：`translateY(-1px)` + 阴影微增；过渡 150–180ms

### 6.2 按钮（三级）

| 类型 | 样式 |
|------|------|
| 主按钮 | 底 `--accent`，字 `--accent-text`；hover `--accent-hover` |
| 次按钮 | 底 `--surface`，边 `--border`，字 `--text`；hover `--surface-hover` |
| 文字按钮 | 无边无底，字 `--accent` 或 `--text-muted` |

禁止渐变、发光、立体浮雕。高度建议 **36px**（sm **32px**）。

### 6.3 输入框

- 高 36px；边 `--border`；聚焦边/环用 `--accent`（低存在感，`box-shadow: 0 0 0 3px var(--accent-soft)`）
- 禁止彩色粗光晕

### 6.4 导航（侧栏）

- 底 `--surface` 或 `--bg`；分割 `--border`
- 默认项：`--text-secondary`；hover：`--surface-hover`
- 选中：字 `--accent` + 底 `--accent-soft`（或左侧 2px accent 条，二选一，全站统一）
- 禁止花哨下拉动画与高饱和块

### 6.5 表格

- 表头：`--text-muted` + 底 `--bg-subtle`
- 行分割：`--border`；hover 行：`--surface-hover`
- 密度舒适，行高约 44–48px

### 6.6 Toast / 状态

- 使用功能色 soft 底 + 深字；勿用霓虹边

## 7. 动效与交互

### 7.1 原则

微动效、低存在感、服务体验、不炫技。

### 7.2 允许

- hover：轻上浮（1–2px）、背景/透明度变化
- 出现：opacity 淡入
- 切换：柔和 fade，**≤ 200ms**，`ease-out`

### 7.3 禁止

弹跳、旋转、大幅缩放、抖动、粒子、流光、渐变流动、滚动劫持花活。

```css
:root {
  --ease: cubic-bezier(0.22, 1, 0.36, 1);
  --dur: 160ms;
}
```

---

## 8. 图片与素材

- 封面等真实素材保持原图比例，`object-fit: cover`，圆角用 `--radius-sm`
- 不叠加高饱和滤镜、不拉伸畸变
- 少用装饰插图；空状态以简短文案 + 轻量线框即可

---

## 9. AI / Cursor 强制规则

1. 页面与样式完全遵从本文 Token，不自创调色板或第二套风格。
2. 新增模块必须匹配极简克制审美与间距刻度。
3. 与旧 CSS 冲突时，按本文修正，禁止「兼容」出双风格并存新代码。
4. 禁止顺手加装饰、渐变、特效、多余 UI。
5. 改视觉前打开本文件与 `.cursor/rules/ui-design-system.mdc`。
