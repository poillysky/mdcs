## 已知问题 / 可增强

1. **actor**：SONE-001 为 Jav321 **精简模板**（无 star/company/genre 链接）；完整页或 `/video/{cid}` 直链可能有结构化演员。
2. **rating**：✅ `parseJav321Rating`（对齐 MDCX `getScore`）。
3. **votes**：可选采 `お気に入り登録数`；与 MDCX `<votes>`（javdb wanted）语义不同，写入前需约定。
4. 多源合并时 actor/genre/series 仍建议 JavBus / DMM 补全。
